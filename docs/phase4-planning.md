# Phase 4: 실데이터 연동 및 매물 그래프 확장 계획서

## 1. 개요
현재의 거시적 지역 통계(평균가, 변동률) 노드 시각화를 넘어, 사용자의 구체적인 예산과 조건에 부합하는 **'실제 매물(Properties)' 단위의 데이터**를 지식 그래프에 노드로 동적 렌더링하여 직관적이고 새로운 매물 탐색 경험을 제공합니다.

## 2. 세부 구현 계획

### Step 1: Supabase 데이터베이스 확장 (매물 테이블 설계)
- **`properties` 테이블 신설**
  - `id`: 매물 고유 ID
  - `region_code`: 지역 코드 (기존 지역 테이블과 연결)
  - `name`: 매물명 (예: 서교동 해링턴타워)
  - `deposit`: 보증금 (단위: 만 원)
  - `monthly_rent`: 월세 (단위: 만 원)
  - `address`: 상세 주소
  - `url`: 매물 상세 링크
  - `features`: 특징 (예: "신축, 역세권, 채광 좋음")

### Step 2: AI 의도 추출(LLM) 고도화
- **현재**: `regionName` (지역명), `buildingType` (건물 유형) 추출
- **개선**: 프롬프트 강화를 통해 사용자의 예산과 라이프스타일 조건 추가 파싱
  - `maxMonthlyRent` (최대 허용 월세)
  - `maxDeposit` (최대 허용 보증금)
  - `preferredFeatures` (선호 특징 배열: 역세권, 풀옵션 등)

### Step 3: Graph Mapper 로직 개편 (`lib/graph-mapper.ts`)
- DB에서 사용자의 예산과 조건에 맞는 실제 매물 리스트(Top 3~5개)를 쿼리해옵니다.
- 기존 그래프의 **[추천 지역]** 노드 아래에 **[매물 노드 A], [매물 노드 B]**들을 방사형 가지로 연결하여 시각화합니다.
- 매물 노드의 시각적 차별화: 기본 통계 노드와 구별되도록 Wabi-Sabi 테마의 포인트 컬러(예: 차분한 오렌지 브라운)를 적용하여 눈에 띄게 배치합니다.

### Step 4: UI 인터랙션 및 맞춤형 브리핑(우측 패널) 고도화
- 사용자가 그래프 캔버스에서 특정 '매물 노드'를 클릭할 경우:
  1. 우측 패널 상단에 매물의 상세 스펙(가격, 주소, 특징)을 UI 카드로 예쁘게 표기합니다.
  2. 하단에는 LLM이 **"이 매물이 사용자의 초기 조건(예: 홍대 근처 60만 원 이하)에 왜 찰떡궁합인지"** 설득력 있고 다정하게 설명하는 1:1 맞춤형 컨설팅 텍스트를 즉시 생성하여 렌더링합니다.

## 3. 기대 효과
- **UX 혁신**: 기존 직방/다방의 획일화된 '리스트+지도' 뷰에서 벗어나, 내 조건 ➡ 추천 지역 ➡ 최적 매물로 이어지는 직관적인 '마인드맵' 형태의 재미있는 탐색 경험을 제공합니다.
- **서비스 신뢰도 상승**: AI가 단순히 매물을 던져주는 것이 아니라, 내 조건을 고려한 추천 사유를 사람처럼 다정하게 브리핑해주므로 사용자의 심리적 안도감과 신뢰도가 대폭 상승합니다.
